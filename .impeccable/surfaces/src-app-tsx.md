# Discover and publish

Mode: Experience for discovery, Operate for publishing. The user approved the gallery-first plan and asked to build it with Impeccable and Fancy Components. This is a code-led implementation of that chosen direction, not a new identity tournament.

## Direction contract

THESIS: Play the component, discover its maker, take its source. The interface is a community workbench, not a marketing homepage or paid marketplace.

OWN-WORLD: OLED black, near-white text, broad Grotesque display lettering, thin neutral rules, quiet navigation. Preview stages belong to the submitted work; platform chrome stays monochrome.

STORY: A visitor can browse without an account, activate a preview, inspect licensing, find its creator, then save or publish their own work.

FIRST VIEWPORT: Compact wordmark and navigation. Search, feed controls, and filters lead directly into large playable preview stages with unobscured maker credits below. The user removed the marketing headline and all filler.

FORM: The previously proposed gallery-first structure, first and already chosen. Seed key: user-approved-plan-2026-10-12. Signature interaction: a component stage expands into its detail-stage position, with the same preview identity; selected navigation and feed indicators track their related controls. No generic blur, page-entry choreography, or decorative button animation. Live previews stay isolated and refresh as code changes.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Constraints: no invented contributors, statistics, or testimonials. Initial entries are real Fancy Components projects, explicitly marked community-listed. Never claim the maintainer submitted them. No production DNS changes in this build.
